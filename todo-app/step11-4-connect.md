# STEP 11-4. 화면과 서버 연결하기 — 거실과 주방 사이에 문 달기 (PLAN P-13)

## 📚 이 단계에서 참고하는 파일

| 참고 파일 | 무엇을 가져오나 | 왜 참고하나 |
|---|---|---|
| API-SPEC.md | `/health`, 공통 규칙 | 화면이 서버에 **어떤 주소로** 물어볼지 정해요. |
| ARCHITECTURE.md | 화면 ↔ 서버 연결 방식 | 화면은 요청만, 서버는 대답만 하는 **역할 나눔**을 지켜요. |
| SCREEN-SPEC.md | 오류 상태 표시 | 연결 실패 때 **무엇을 보여 줄지** 근거예요. |
| PLAN.md | P-13 | 이번엔 **연결만**. 할 일 기능은 아직이에요. |

---

## 🧸 쉽게 말하면

거실(화면)과 주방(서버)을 따로 만들었어요. **사이에 문이 없으면** 주문을 전달할 수 없어요.
이 단계에서는 **문을 달고, 문이 열리는지 딱 한 번 시험**해요.

## ❓ 왜 따로 시험할까?

```
❌ 기능을 다 만들고 처음 연결     → 카드가 안 생김. 화면? 서버? 저장? 연결? 어디가 문제?
✅ 연결만 먼저 시험              → 안 되면 원인은 "연결" 하나
```

## 🚪 왜 문이 필요할까? (CORS)

브라우저는 안전을 위해 **다른 방 번호(포트)끼리는 마음대로 대화하지 못하게** 막아요.

```
화면 (localhost:5173)  ──요청──X──▶  서버 (localhost:8000)
                          🚫 "다른 방이라 안 돼요!"
```

서버가 **"5173번 방에서 오는 요청은 받아 줄게"**라고 허락해야 해요. 이 허락을 **CORS 설정**이라고 해요.

## 🎯 이 단계가 끝나면

화면에 **연결 상태 표시**(또는 "서버 연결 확인" 버튼)가 있고, 서버가 켜져 있으면 "서버 연결됨", 꺼져 있으면 "서버 연결 안 됨"이 보여요.

---

## 🗣️ AI와 대화하며 진행하기

### 대화 1. 계획 받기

- claude-code 입력
```claude-code
PLAN의 P-13을 "진행 중"으로 바꾸세요.
API-SPEC.md와 SCREEN-SPEC.md를 기준으로 화면과 서버가 연결되는지만 확인하려고 합니다. 할 일 기능은 아직 만들지 마세요.
1. 화면에 서버 연결 상태를 보여 주는 부분을 만들고, 서버의 /health를 불러 결과를 보여 주세요. 실패하면 "서버 연결 안 됨"처럼 안내하세요.
2. 서버에는 화면 주소(http://localhost:5173)만 허락하는 CORS 설정을 추가하세요. 모든 주소를 허락하지는 마세요.
3. 서버 주소를 코드 곳곳에 직접 쓰지 말고 한 곳에서 관리하세요.
바꿀 파일과 이유를 먼저 보여 주고 승인을 기다리세요.
```

**이 문장을 넣는 이유**

| 문장 | 이유 |
|---|---|
| "화면 주소만 허락" | 모든 주소를 허락하면 아무 사이트나 내 서버에 요청할 수 있어 위험해요 |
| "한 곳에서 관리" | 나중에 주소가 바뀌면 한 곳만 고치면 돼요 |
| "실패하면 안내" | SCREEN-SPEC의 오류 상태를 지키려고 |

**AI가 만들 서버 코드 예시 (읽기만 해요)**

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],   # 이 화면 주소만 허락
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 🔍 고장 원인을 보는 법: 브라우저 개발자 도구

연결이 안 되면 브라우저에서 **F12**를 눌러요. (Mac: `Cmd + Option + I`)

| 탭 | 보는 것 | 비유 |
|---|---|---|
| **Console** | 빨간 오류 글자 | 비상벨 |
| **Network** | 화면이 서버에 보낸 요청과 대답 | 택배 송장 |

| Network의 Status | 뜻 |
|---|---|
| 200 | 성공 |
| (빨간색) CORS error | 문 허락이 없음 → CORS 설정 확인 |
| (failed) | 서버가 꺼져 있음 |
| 404 | 주소가 틀림 |

## 😵 막혔을 때

| 보이는 것 | 뜻 | AI에게 할 말 |
|---|---|---|
| Console: `blocked by CORS policy` | 서버가 화면 주소를 허락 안 함 | "CORS 설정에 http://localhost:5173이 있는지, 서버를 다시 켰는지 확인해 주세요" |
| Console: `Failed to fetch` / `ERR_CONNECTION_REFUSED` | 서버가 꺼져 있음 | "API 서버가 켜져 있는지 확인해 주세요" |
| Network: 404 | 주소 철자 틀림 | "화면이 부르는 주소와 서버의 /health 주소를 비교해 주세요" |
