# STEP 2. AGENTS.md — AI 도우미와 "일하는 약속" 정하기

> **AGENTS.md** = "AI가 일할 때 지킬 규칙" (**AI**가 읽는 파일)

## 📚 이 단계에서 참고하는 파일

| 참고 파일 | 무엇을 가져오나 | 왜 참고하나 |
|---|---|---|
| README.md | 프로젝트 소개, 현재 상태 | **무슨 프로젝트인지** 알아야 AI가 맞는 규칙을 제안할 수 있어요. "AI 기능 없음" 같은 방향도 규칙의 "목적"에 들어가요. |

## 🔗 이 파일을 나중에 참고하는 곳

| 파일·단계 | 무엇을 가져가나 |
|---|---|
| STEP 3 DECISIONS | "확정한 것만 적고 모르면 묻는다"는 규칙 |
| STEP 4 PLAN | "실행하지 않은 검사는 통과라고 하지 않는다" → 상태 규칙 |
| **모든 새 대화** | AI가 일하기 전에 지킬 규칙 전부 |

---

## 🧸 쉽게 말하면

AGENTS.md는 **AI 도우미에게 주는 약속 카드**예요. 학교의 **"교실 규칙"** 포스터처럼, AI가 일을 시작할 때마다 읽고 지켜요.

```
📋 교실 규칙              📋 AGENTS.md
- 수업 전에 교과서 펴기     - 파일을 바꾸기 전에 문서 먼저 읽기
- 모르면 손 들고 질문      - 모르면 추측하지 말고 질문
- 선생님 허락 받고 나가기   - 사람 허락 받고 파일 바꾸기
```

---

## ❓ 왜 필요할까?

AI는 **새 대화를 열 때마다 앞의 대화를 잊어요.**

| AGENTS.md가 없으면 | AGENTS.md가 있으면 |
|---|---|
| 매번 "허락 받고 해", "먼저 읽어"를 다시 말해야 함 | AI가 파일을 읽고 스스로 지킴 |
| AI가 바로 설치·삭제를 실행할 수 있음 | "실행 전에 설명하고 허락받기"를 지킴 |
| AI가 "다 했어요"만 말하고 끝 | 바뀐 파일과 실행 결과를 보고함 |

### README와 뭐가 달라요?

| | README.md | AGENTS.md |
|---|---|---|
| 누가 읽나 | **사람** | **AI** |
| 무엇을 알려 주나 | 이 프로젝트가 **무엇인지** | AI가 **어떻게 일해야 하는지** |
| 비유 | 책 표지 | 교실 규칙 |

> ⚠️ AGENTS.md는 **약속**이지 **자물쇠**가 아니에요. 적어 둬도 AI가 어길 수 있어요. 그래서 **사람이 결과를 확인하는 일**은 계속해야 해요.

### 앞으로 만들 파일들 (규칙에 미리 적어 둬요)

AGENTS에는 "일하기 전에 이 파일들을 읽어라"를 적어요. 아직 없는 파일도 **미리 적어 두면**, 파일이 생긴 뒤 AI가 자동으로 읽어요.

| 파일 명 | 역할 |
|---|---|
| README.md | 사람이 처음 읽는 표지. 무엇인지, 지금 어디까지 됐는지, 어떻게 실행하는지 |
| DECISIONS.md | 사람이 확정한 결정과 그 이유. AI는 제안만 하고 확정은 사람이 함 |
| PLAN.md | 앞으로 할 작업 + 지금 상태 + 실제 확인 결과 + 다음 행동 |
| PRD.md | 무엇을 만들지 정한 요구 문서. AI가 초안을 쓰고 사람이 판정·확정 |

## 🗣️ AI와 대화하며 만들기

### 대화 1. AI에게 어떤 약속이 필요한지 물어보기

- claude-code 입력
```claude-code
README.md를 읽으세요. 이제 AGENTS.md를 만들려고 합니다.
AGENTS.md는 앞으로 매번 새 대화를 시작하는 AI가 읽는 작업 규칙입니다.
AI가 이 프로젝트에서 일을 시작하기 전에 꼭 알아야 할 질문을 5~6개 알려 주세요.
각 질문이 없으면 어떤 문제가 생기는지도 한 줄씩 적어 주세요.
아직 파일은 만들지 마세요.
```

**AI 대답 예시**
> 1. 이 프로젝트는 무엇인가요? → 없으면 엉뚱한 앱을 만들 수 있어요.
> 2. 일하기 전에 무엇을 읽어야 하나요? → 없으면 추측으로 일해요.
> 3. 무엇은 바꿔도 되고 무엇은 안 되나요? → 없으면 필요 없는 파일까지 바꿔요.
> 4. 언제 사람의 허락이 필요한가요? → 없으면 설치·삭제를 바로 실행해요.
> 5. 일을 끝내면 무엇을 보고해야 하나요? → 없으면 "다 했어요"만 말해요.
> 6. 위험한 일은 어떻게 다루나요? → 없으면 비밀번호가 기록에 남을 수 있어요.

### 대화 3. 규칙 초안 받기

> ❓ **"일하기 전"이 무슨 뜻이에요?**
> 프로젝트를 시작할 때 한 번이 아니라, **작업 요청을 받을 때마다, 파일을 바꾸거나 명령을 실행하기 전**이라는 뜻이에요. 그래서 프롬프트에 그렇게 분명히 써요.

- claude-code 입력
```claude-code
AGENTS.md를 아래 칸으로 만들려고 합니다.
- 목적 / 환경 / 작업 전 / 변경 범위 / 완료 확인 / 안전
규칙을 정할 때 다음을 꼭 넣어 주세요.
- 작업 요청을 받을 때마다, 파일을 바꾸거나 명령을 실행하기 전에 README, DECISIONS, PLAN, PRD를 읽는다. 없는 파일은 없다고 말한다.
- 읽은 내용을 바탕으로 계획(바꿀 파일, 확인 방법)을 먼저 설명한다.
- 사람이 승인하기 전에는 파일을 바꾸거나 명령을 실행하지 않는다.
- 결정은 사람이 한다. AI는 제안만 하고, 확정되지 않은 내용을 확정처럼 적지 않는다.
- 정한 내용(DECISIONS)과 다른 요청이 오면 멈추고 사람에게 묻는다.
- 한 파일을 바꾸면 함께 고쳐야 할 파일이 있는지 알려 준다.
- 실행하지 않은 검사를 통과했다고 말하지 않는다.
환경 칸은 "아직 미정"으로 두세요. 기능 목록은 넣지 마세요.
초안을 대화에만 보여 주세요.
```

**이 문장을 넣는 이유**

| 문장 | 이유 |
|---|---|
| "작업 요청을 받을 때마다, 파일을 바꾸기 전에" | "일하기 전"을 AI와 내가 같은 뜻으로 이해하게 |
| "없는 파일은 없다고 말한다" | 없는 파일의 내용을 **지어내지** 않게 |
| "결정은 사람이 한다" | DECISIONS·PRD를 AI가 마음대로 확정하지 않게 |
| "함께 고쳐야 할 파일을 알려 준다" | 파일끼리 서로 다른 말을 하지 않게 (함께 고치기) |
| "기능 목록은 넣지 마세요" | 기능은 PRD에. AGENTS는 **규칙만** |

**AI 대답 예시**

```markdown
# 프로젝트 작업 규칙

## 목적
할 일을 카드로 관리하는 웹앱 Task Flow를 만든다. 앱 안에 AI 기능은 넣지 않는다.

## 환경
아직 미정이다. 기술을 확정하면 DECISIONS.md를 근거로 이 칸을 채운다.

## 작업 전
- 작업 요청을 받을 때마다, 파일을 바꾸거나 명령을 실행하기 전에 README.md, DECISIONS.md, PLAN.md, PRD.md를 읽는다. 없는 파일은 없다고 말한다.
- 이해한 내용과 작업 계획(바꿀 파일, 확인 방법)을 먼저 설명한다.
- 정보가 부족하면 추측하지 말고 질문한다.

## 변경 범위
- 사람이 승인한 작업만 한다. 한 번에 작은 작업 하나만 한다.
- 결정은 사람이 한다. 확정되지 않은 내용을 확정처럼 적지 않는다.
- DECISIONS와 다른 요청이 오면 멈추고 사람에게 확인한다.
- 한 파일을 바꾸면 함께 고쳐야 할 파일이 있는지 알려 준다.

## 완료 확인
- 실제로 바꾼 파일을 보고한다.
- 실행한 명령과 결과를 구분해 적는다.
- 실행하지 않은 검사는 "미실행"으로 적는다.

## 안전
- 비밀번호, API 키, 개인정보를 파일·채팅·Git 기록에 넣지 않는다.
- 삭제, 덮어쓰기, 설치, 관리자 권한이 필요한 명령은 실행 전에 설명하고 다시 승인받는다.
```

## 🧪 약속이 진짜 작동하는지 시험하기

**새 대화(새 채팅)를 열고** 아래만 입력해 보세요. 앞의 대화를 모르는 AI가 **파일만 보고** 약속을 지키는지 확인하는 시험이에요.

- claude-code 입력 (새 대화에서)
```claude-code
이 폴더에서 할 일 앱 작업을 이어서 하려고 합니다. 먼저 무엇을 읽어야 하고, 어떤 규칙을 지켜야 하는지 설명해 주세요. 아직 아무것도 바꾸지 마세요.
```

- [ ] AI가 AGENTS.md를 읽고 규칙을 말했나요?
- [ ] "허락 전에는 바꾸지 않는다"를 말했나요?
- [ ] DECISIONS, PLAN, PRD가 **아직 없다**고 말했나요? (지어내지 않았나요?)

> 💡 새 대화에서도 규칙을 말한다면 **"대화는 사라져도 파일은 남는다"**가 증명된 거예요!
> 📌 이 시험 결과는 STEP 4에서 PLAN의 "실제 검증 결과"에 적어요. **기억해 두세요.**

## 🔄 함께 고치기

| 이번에 바뀐 것 | 함께 고칠 파일 | 고칠 칸 | 이유 |

```claude-code
AGENTS.md가 생겼으니 README.md를 함께 고치려고 합니다.
```

| 언제 | 고칠 칸 |
