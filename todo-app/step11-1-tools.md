## 🧸 쉽게 말하면

요리하기 전에 **냄비, 칼, 도마**가 있는지 확인하는 단계예요.

| 도구 | 하는 일 | 비유 |
|---|---|---|
| Git | 저장 기록 남기기 | 세이브 버튼 |
| Node.js + npm | 화면(React)을 만들고 실행 | 화면용 냄비 |
| Python + uv | 서버(FastAPI)를 만들고 실행 | 서버용 냄비 |

> 💡 `uv`는 파이썬 도구를 설치하고 실행해 주는 도우미예요.

## 🎯 이 단계가 끝나면

```
git --version      → git version 2.xx
node --version     → v20.xx 또는 v22.xx
npm --version      → 10.xx
python --version   → Python 3.1x   (Windows는 py --version일 수도 있어요)
uv --version       → uv 0.x
```

## 🗣️ AI와 대화하며 진행하기

### 대화 1. 새 대화 열고 규칙부터 확인 (새 채팅!)

- claude-code 입력
```claude-code
새 작업 대화입니다. 이전 대화를 추측하지 마세요.
AGENTS.md를 먼저 읽고 지킬 규칙을 말해 주세요. 그다음 README, DECISIONS, ARCHITECTURE, PLAN의 구현 인계를 읽으세요.
PLAN의 P-10을 "진행 중"으로 바꾸세요. 이번 목표는 도구 확인뿐입니다. 아무것도 설치하지 마세요.
제 운영체제와 터미널 종류를 먼저 확인하고, Git, Node.js, npm, Python, uv가 설치되어 있는지 확인하는 명령을 보여 주세요.
```

- [ ] AI가 AGENTS 규칙("허락 전엔 실행 안 함" 등)을 말했나요?
- [ ] 바로 설치하지 않고 **확인 명령만** 보여 줬나요?

- claude-code 입력
```claude-code
확인 명령을 실행하고, 도구마다 결과를 표로 보여 주세요. 칸: 도구 / 실행한 명령 / 결과 원문 / 설치됨·없음
```

**AI 대답 예시**

| 도구 | 명령 | 결과 | 상태 |
|---|---|---|---|
| Git | git --version | git version 2.45.1 | 설치됨 |
| Node.js | node --version | 'node'은(는) 내부 또는 외부 명령이 아닙니다 | **없음** |
| Python | python --version | Python 3.12.4 | 설치됨 |
| uv | uv --version | 명령을 찾을 수 없음 | **없음** |

---

> 📌 실습 자료에 **`readiness-check.py`**(개발환경 점검 스크립트)가 있다면, AI에게 "이 스크립트를 읽고 무엇을 확인하는지 설명한 뒤 실행해 결과를 보여 주세요"라고 요청해 함께 확인해요.

### 대화 2. 없는 도구만 설치하기

- claude-code 입력
```claude-code
없는 도구만 설치하려고 합니다. 도구마다 아래를 알려 주세요.
1. 공식 설치 페이지 주소
2. 설치 방법 (한 번에 하나씩)
3. 관리자 권한이 필요한지
4. 설치 후 확인할 명령
아직 설치하지 마세요. 관리자 권한이나 보안 설정을 바꾸는 일은 제가 강사님께 먼저 확인하겠습니다.
```

> ⚠️ **보안 설정을 끄라고 하면 멈추세요.** "실행 정책을 바꾸세요", "보안 프로그램을 끄세요" 같은 안내가 나오면 혼자 하지 말고 **강사님께 물어보세요.**

> 💡 설치 후에는 **터미널을 닫았다가 새로 열어야** 새 도구를 알아봐요.

- claude-code 입력
```claude-code
Node.js를 설치하고 터미널을 새로 열었습니다. 다시 node --version과 npm --version을 실행해 결과를 보여 주세요.
```

## 😵 막혔을 때

| 보이는 글 | 뜻 | 해결 |
|---|---|---|
| `'node'은(는) 내부 또는 외부 명령...이 아닙니다` / `command not found` | 설치 안 됨, 또는 설치 직후 터미널을 안 다시 엶 | 터미널 새로 열기 → 그래도 안 되면 설치 |
| `python`은 안 되는데 `py`는 됨 | Windows에서 흔한 일 | AI에게 "py로 실행해 주세요" |
| `npm.ps1 파일을 로드할 수 없습니다` (Windows) | PowerShell 보안 정책 | **혼자 바꾸지 말고 강사님께.** 터미널 종류를 cmd로 바꾸는 방법도 있어요 |
