# STEP 8. DATA-MODEL.md — "무엇을 저장할까?" (PLAN P-07)

> **DATA-MODEL.md** = 카드 하나에 **무엇을, 어떤 이름과 뜻으로** 저장하는지

## 📚 이 단계에서 참고하는 파일

| 참고 파일 | 무엇을 가져오나 | 왜 참고하나 |
|---|---|---|
| PRD.md | 4. Task 카드 정보와 상태 규칙 | 저장할 정보(제목·설명·상태)와 **규칙**(제목 필수, 상태 3개)이 여기 있어요. |
| SCREEN-SPEC.md | 카드에 보여 줄 정보 | 화면에 보이는 정보는 **저장되어 있어야** 다시 보여 줄 수 있어요. |
| ARCHITECTURE.md | 저장소 = SQLite | 어디에 저장하는지 알아야 "SQLite 변환 초안"을 쓸 수 있어요. |
| DECISIONS.md | D-002 (되돌리기 허용) | 상태 값 표의 "되돌리기 허용" 칸의 근거예요. |

## 🔗 이 파일을 나중에 참고하는 곳

| 파일·단계 | 무엇을 가져가나 |
|---|---|
| STEP 9 API-SPEC | **필드 이름을 그대로** 써요 (title, status …) |

## 🧸 쉽게 말하면

DATA-MODEL은 **사물함 이름표 규칙**이에요.

```
🗄️ 사물함 한 칸 = 할 일 카드 하나
  번호   (학교가 정해 줌, 내가 못 바꿈)     → id
  이름표 (내가 씀, 꼭 있어야 함)            → title
  메모   (내가 씀, 없어도 됨)               → description
  상태   (할 일 / 진행 중 / 완료 중 하나)    → status
  만든 날 (학교가 적어 줌)                  → created_at
  고친 날 (학교가 적어 줌)                  → updated_at
```

---

## ❓ 왜 필요할까?

| 정하지 않으면 | 생기는 일 |
|---|---|
| 화면은 "제목", 서버는 "name", 저장소는 "title"이라고 부름 | 서로 못 알아들어 저장이 안 됨 |
| 상태에 아무 글자나 들어감 | "완료됨", "done", "끝"이 섞여 화면이 헷갈림 |
| 설명이 없을 때 "빈칸"인지 "없음"인지 안 정함 | 어떤 카드는 보이고 어떤 카드는 오류 |

### 대화 2. 고를 것은 비교받고 내가 고르기

| 골라야 할 것 | 선택지 |
|---|---|
| 설명이 없을 때 | `null`(없음) / 빈 문자열 `""` |
| 번호는 누가 만드나 | 브라우저 / 서버·저장소 |
| 시각은 누가 적나 | 브라우저 / 서버 |
| 상태 값 | 아무 글자 / 정해진 3개만 |

- claude-code 입력
```claude-code
위 네 가지를 각각 두 선택지로 비교하고, 고르면 화면과 서버에 어떤 차이가 생기는지 쉽게 설명하세요. 최종 선택은 기다리세요.
```

> 💡 초보자 팁: 번호와 시각은 **서버가** 만들고, 상태는 **정해진 3개만** 쓰는 게 실수가 적어요.

- claude-code 입력
```claude-code
제 선택입니다. 설명 없음은 null, 번호는 서버·저장소, 시각은 서버, 상태는 정해진 3개(TODO, IN_PROGRESS, DONE)만 씁니다.
DATA-MODEL.md의 "데이터 규칙 결정 기록" 표에 대안, 제 선택, 이유, API·화면 영향을 적어 주세요.
```

> 📌 이런 **데이터 세부 선택**은 DATA-MODEL 안의 "데이터 규칙 결정 기록"에 적어요. DECISIONS에는 제품 모양을 바꾸는 큰 선택만 적어요.

## 🔄 함께 고치기

| 이번에 바뀐 것 | 함께 고칠 파일 | 고칠 칸 | 이유 |
|---|---|---|---|
| 제목 100자 같은 **새 규칙**을 정함 | PRD | 4. Task 카드 정보 | 요구에 없던 규칙이면 PRD에도 (문서가 같은 말을 하게) |
| DATA-MODEL 생김 | ARCHITECTURE | 상세 설계 연결 | 데이터 설계 위치를 "작성됨"으로 |
| DATA-MODEL 확정 | PLAN | P-07 상태, 검증 결과, 다음 행동 | 진행 상황 |
| 문서 추가 | README | 프로젝트 문서 | DATA-MODEL 추가 |

- claude-code 입력
```claude-code
DATA-MODEL을 확정했으니 함께 고칠 곳을 표로 먼저 보여 주세요.
- PRD.md: DATA-MODEL에서 새로 정한 규칙(예: 제목 길이)이 PRD 4번에 없으면 추가 후보로
- ARCHITECTURE.md 상세 설계 연결: 데이터 = DATA-MODEL.md (작성됨)
- PLAN.md: P-07 "완료", 실제 검증 결과, 다음 행동 "P-08 API-SPEC"
- README.md: 프로젝트 문서에 "DATA-MODEL.md: 저장할 정보" 추가
확인하면 고치고 바뀐 줄만 보여 주세요.
```
