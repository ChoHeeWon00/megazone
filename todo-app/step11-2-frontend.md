# STEP 11-2. 화면 틀 만들기 — 거실 만들기 (PLAN P-11)

## 📚 이 단계에서 참고하는 파일

| 참고 파일 | 무엇을 가져오나 | 왜 참고하나 |
|---|---|---|
| ARCHITECTURE.md | 화면 = React, 실행 위치 | **어떤 기술로, 어느 폴더에** 만들지 정해요. |
| PLAN.md | 구현 인계, P-11 | 이번엔 **빈 화면만**. 기능은 아직이에요. |
| AGENTS.md | 안전 (설치·덮어쓰기 전 승인) | 프로젝트를 만들면 부품을 설치해요. 기존 문서를 **덮어쓰지 않게** 해요. |
| README.md | 실행 방법 칸 | 실행해 본 명령을 **여기에 적을** 거예요. |

## 🧸 쉽게 말하면

아직 가구(기능)는 없는 **빈 거실**을 만들어요. 불이 켜지는지만 확인해요.

## 🎯 이 단계가 끝나면

```
http://localhost:5173

┌──────────────────────┐
│  Task Flow            │
│  (아직 비어 있어요)     │
└──────────────────────┘
```

> 💡 `localhost`는 **"내 컴퓨터"**라는 뜻이에요. `5173`은 방 번호(포트)예요. 다른 사람은 이 주소로 들어올 수 없어요.

---

## 🗣️ AI와 대화하며 진행하기

### 대화 1. 계획 받기

- claude-code 입력
```claude-code
PLAN의 P-11을 "진행 중"으로 바꾸세요.
ARCHITECTURE.md를 기준으로 frontend 폴더에 React 기본 화면만 만들려고 합니다.
할 일 기능, 서버 연결, 저장소는 아직 만들지 마세요.
1. 실행할 명령과 만들어질 폴더·파일을 순서대로 보여 주세요.
2. 기존 문서 파일을 덮어쓰거나 지우는 일이 있는지 알려 주세요.
3. 만든 뒤 화면을 확인할 주소를 알려 주세요.
계획만 보여 주고 승인을 기다리세요.
```

**AI 대답 예시**
> 1. `npm create vite@latest frontend -- --template react` 로 frontend 폴더를 만듭니다.
> 2. `cd frontend` → `npm install` 로 필요한 부품을 받습니다.
> 3. 첫 화면 글자를 "Task Flow"로 바꿉니다.
> 4. `npm run dev` 로 실행하면 http://localhost:5173 에서 볼 수 있습니다.
> 기존 문서는 건드리지 않습니다.

> 📌 위 명령은 **외울 필요 없어요.** "어디에 무엇이 생기는지"만 확인하면 돼요.

- [ ] `frontend` 폴더 **안에만** 만드나요?
- [ ] 할 일 기능을 미리 만들지 않나요?

---

### 대화 2. 실행하고 내 눈으로 확인

- claude-code 입력
```claude-code
계획을 승인합니다. 한 단계씩 실행하고 각 명령의 결과를 보여 주세요.
프로젝트를 만드는 명령이 질문을 하며 멈추면, 질문 없이 진행하는 옵션으로 다시 실행하세요.
마지막에 화면 서버를 켜고 주소를 알려 주세요. 서버는 켜 둔 채로 두세요.
```

- [ ] 브라우저에서 "Task Flow" 글자가 보이나요?
- [ ] 터미널에 빨간 오류 글자가 없나요?

> 💡 화면 서버가 켜져 있는 동안 **그 터미널은 계속 일하는 중**이에요. 닫으면 화면도 꺼져요.

| 화면 켜는 명령을 실제로 실행함 | README | 실행 방법 | **실행해 본 명령만** 적기 |
| frontend 폴더 생김 | README | 프로젝트 문서(또는 폴더 안내) | 폴더 역할 안내 |

```claude-code

- PLAN.md: P-11 "완료", 실제 검증 결과에 실행 명령·주소·결과, 다음 행동 "P-12 서버 틀"
- README.md: 실행 방법에 화면을 켜는 방법을 실제로 실행한 명령으로 추가 (서버는 아직 없음)
- README.md: 프로젝트 문서에 "frontend/: 화면(React)" 추가
```

## 😵 막혔을 때

| 보이는 글 | 뜻 | 해결 |
|---|---|---|
| 프로젝트 만드는 중 질문이 나오고 멈춤 | 만드는 도구가 선택을 기다림 | "질문 없이 진행하는 옵션으로 실행해 주세요" |
| `npm ERR! enoent ... package.json` | 엉뚱한 폴더에서 실행함 | "현재 폴더를 확인하고 frontend 안에서 실행해 주세요" |
| `Port 5173 is in use` | 이미 다른 화면 서버가 켜져 있음 | 다른 터미널의 화면 서버를 끄기 |
| 브라우저에 "사이트에 연결할 수 없음" | 화면 서버가 꺼져 있음 | 터미널에서 서버가 켜져 있는지 확인 |
